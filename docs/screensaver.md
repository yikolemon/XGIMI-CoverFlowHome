# 本地视频屏保：初版需求与设计

## 1. 使用目标与默认约定

用于投影仪睡前长时间播放本地视频。这是应用内屏保，不是 Android 系统 DreamService，不修改默认桌面、系统休眠策略或系统音量。

用户未指定的细节，初版作以下约定：

- **自动启动**：桌面连续无操作 10 分钟。可在设置中选关闭、1、5、10、15、30、60 分钟。键盘/遥控器/触摸操作重新计时；壁纸自动轮换不重置计时。
- **计时范围**：只在桌面可见、有窗口焦点、没有打开应用库时计时。离开桌面、打开设置或系统弹窗时取消；返回桌面后重新计时。
- **手动启动**：焦点先进入右上角按钮，再在 2 秒内独立按三次“上”。现有按钮短按打开应用库，长按打开壁纸设置；本版复用该入口，不改变原功能。进入按钮的那次上键不计数，长按产生的重复事件不计数，其他按键或失去焦点取消组合。
- **视频来源**：不联网、不捆绑个人视频。设置中用系统文件选择器一次选入最多 20 个本地视频，复制到私有目录；也支持自行放到应用外部文件目录的 `screensaver/` 中。默认静音，可在设置中打开声音。
- **播放**：记住上次选择，单个视频循环播放；按比例显示，允许黑边。推荐 1080p H.264/AAC MP4，具体解码能力取决于电视/投影仪。
- **选片**：播放时按“下”才创建底部横向封面条；左右移动、确定切换并收起。上键收起，8 秒无操作自动收起。
- **退出**：600 毫秒内两次独立返回键。第一次收起封面条/显示提示，不退出；其他按键取消双击。Home、关屏、切到后台也停止并释放播放器。

## 2. 资源边界

- 桌面不创建 MediaPlayer、SurfaceView、视频封面缓存或视频工作线程，只持有一个可取消的延迟回调和少量设置/按键状态；未配置视频时不排空闲定时任务。
- 播放使用独立的非导出 Activity、原生 MediaPlayer 和 SurfaceView，不添加播放器依赖，不运行 Service、轮询或后台播放。
- 从桌面进入屏保后释放桌面壁纸和卡片缓存；返回时使用已有后台加载逻辑恢复。
- 只有按“下”时提取可见视频的缩略图，输出目标 240×135，缓存最多 6 张，后台队列有上限。收起选片条后清理缩略图引用/排队任务。
- API 26 不使用可能解码整张 4K 帧的缩略图兜底，显示带名称的占位卡；API 27+ 使用缩放帧接口。
- onPause / Surface 销毁 / 退出都会释放 MediaPlayer；Activity 销毁会取消回调、关闭缩略图线程并释放缓存。只在屏保前台保持屏幕点亮。

## 3. 文件与失败处理

- 导入通过系统提供的 content URI，流式复制，不把视频读入内存；不用永久 URI 授权，不申请管理所有文件权限。
- 单个视频最大 512 MiB，整批最大 2 GiB，保留至少 64 MiB 空闲空间。导入到新 UUID 目录，全部成功后切换偏好设置；失败或取消保留旧集合并清理新文件。
- 被系统杀进程时无法运行清理回调；下次打开屏保设置或导入时清理未被当前选择引用的本功能 UUID 临时目录。不扫描或删除其他目录。
- 外部备用目录：`/sdcard/Android/data/com.gathin.tvhome/files/screensaver/`。无系统文件选择器的旧电视可以通过文件管理器/ADB 放入，再回到屏保设置刷新。
- 不支持的编码/缺失文件尝试下一条，每条最多尝试一次；全失败时停在黑色错误页，仍可选片或双击返回，不无限重试。
- 没有视频时自动启动不弹窗、不进入空屏保；手动启动引导去设置。
- 声音默认关闭。开启时申请音频焦点；失去焦点不允许继续抢播。

## 4. 初版不包含

网络视频、下载、云同步、系统屏保注册、自动关机/睡眠定时、亮度或投影仪风扇控制、后台音频、任意公共目录扫描。

## 5. 验证清单

- 规则单测：三次上键时间窗/重置、双击返回边界、空闲开关和时间计算、媒体扩展名/数量/大小边界。
- 构建：release 单测与 APK；完整 Lint 的历史 TV banner 缺失需与新增问题区分。
- 真机：焦点三次上、按住不误触、桌面计时与系统弹窗/应用库互斥、视频循环和快速切换、静音/音频焦点、单次/双次返回、坏视频、Surface 重建、Home/关屏退出、反复进入退出内存。
- 不把 JVM 单测当成播放器/硬解码/长时间稳定性验证，不宣称未测量的“零内存”或启动速度提升。

## 6. 提交边界

## 7. 实现与二次自查

- `ScreensaverRules`：纯 Java 的组合键、双击、空闲时间、格式/导入预算规则；`ScreensaverRulesTest` 覆盖 12 个用例。
- `CoverFlowHome` / `MainActivity`：输入与窗口焦点驱动单次空闲回调；应用库打开时取消，返回桌面重新计时。右上角按钮保留短按/长按行为。
- `ScreensaverStore`：集合替换/删除串行互斥；持久化成功才删除旧文件。特别处理 SharedPreferences.commit 失败仍可能改变内存状态的问题。
- `ScreensaverActivity`：Surface 和 Activity 生命周期共同约束播放；15 秒准备超时；旧播放器回调/切换任务有身份或代际检查。无视频的自动请求更新计数后直接退出，不留空白屏保。
- `ScreensaverChooser`：缩放封面只按可见范围生成；一个屏保 Activity 复用一个封面线程，收起时清队列，过期结果不进入缓存，避免反复按下开关时叠加解码线程。
- `ScreensaverSettingsActivity`：导入、目录刷新均放后台；提供静音、空闲时长、预览、移除入口。原壁纸设置增加滚动容器，避免多一个入口后在低分辨率屏幕上截断。
- 桌面完全进入后台时清理海报与壁纸引用，包含“设置 → 预览”路径。清理后禁止后台元数据回调重新生成海报，恢复桌面再按可见范围重建。
- 默认静音不申请音频焦点；开启声音后处理暂失焦点（包括视频尚未准备好的情况）、永久失焦和恢复。全部视频失败时归还音频焦点。

## 8. 验证结果与剩余风险

- 本轮新增规则测试 12 项；全量 48 项 JVM 单测通过，Release APK 构建通过。
- 完整 Lint：原有 `MissingTvBanner` 错误仍在；总计 21 项警告，其中本轮两个新增 Activity 的固定横屏警告符合 TV 场景约定。未通过添加 baseline 或关闭检查来掩盖错误。
- 当前 `adb devices` 无连接设备，未执行真机操作、解码、音频焦点和整夜播放验证，也没有实测 CPU/内存数据。
- 不导入实际视频样本，不捆绑未授权素材；初次使用需要自行导入视频或放入文档中的本地目录并刷新。
- 系统文件选择器在部分 TV 上可能不可用；已提供本地目录备用路径。视频扩展名可识别不等于设备一定能解码，失败会有限次尝试其他视频。
- 清理图片引用/关闭播放器不等于 Android 进程内存会立刻降到零；GC、渲染线程和系统解码器的资源回收时机仍由系统决定。
- 本版是应用内屏保，不阻止系统强制休眠/关机，也不能接管其他应用的空闲行为。

### 真机验收建议

1. 设置 1 分钟自动屏保，确认输入会重计时；应用库、壁纸设置、系统弹窗和其他应用前台时不启动。
2. 导入两个可播放 MP4 和一个损坏文件，验证循环、封面、快速切换、超时/错误跳过；全部损坏时仍可双击返回。
3. 确认进入按钮的上键不算三次，按住上不触发；其他键/焦点变化会清空组合。单次返回不退出，600 毫秒内第二次返回才退出。
4. 静音与有声分别测试 Home、关屏、切换其他应用、音频焦点暂失/恢复；返回桌面后壁纸和应用海报应恢复。
5. 连续进入退出 20 次，再进行整夜循环，使用 `adb shell dumpsys meminfo com.gathin.tvhome` 和设备日志观察资源是否持续增长、是否存在解码器错误或异常后台播放。
