# 极米个人桌面

本桌面使用原包名 `com.gathin.tvhome`，可覆盖升级原应用，不再安装并行的新包。

个人壁纸不包含在仓库或 APK 中。可在壁纸设置选择文件夹导入图片，每 30 分钟轮换，也可关闭轮换。

适用于本次定制的极米 G0043：图片壁纸、竖版毛玻璃 Cover Flow、四个常用应用和应用库。

首页顺序：Izuko、弹弹play、网易爆米花、BBLL。
顶部隐藏设置、网络和输入源按钮，保留应用库；不影响网络连接和输入源功能。
设置按钮隐藏后，其长按菜单也不可用，系统设置请通过遥控器或其他应用打开。

## 遥控器操作

- 左右：循环切换封面；中间正面放大，左二右二对称，两侧轻微倾斜 16°。
  少于五个常用应用时，循环复用封面填满两侧，不增加新应用；只有一个应用时不重复显示。
- 确定：打开当前应用。
- 上：聚焦右上角“全部应用”；确定展开应用库。
- 右上角应用库图标默认隐藏，按上才显示；按下、返回或关闭应用库时重新隐藏。
- 在“全部应用”按钮上按下或返回：回到当前封面。
- 主页按下不展开第二排；应用库内部保留自己的导航与返回规则。

## 自己更换壁纸

主页向上选中右上角应用库图标，**长按确定**打开“更换壁纸”。短按仍打开全部应用。
有系统选择器时使用系统选择器；本机无选择器时会申请读取图片权限，并显示纯文件名浏览器。
建议将图片放进共享存储的 `Pictures` 或 `Download` 文件夹。

图片在后台采样、按 EXIF 方向矫正并居中裁剪为 16:9；最大输出 1920×1080，不放大小图。
特别大的原图可能降采样到低于 1080p，以限制解码峰值。只保留一张不超过 512 KiB 的 JPEG，
不缓存原图、缩略图或网络图片。不做新旧壁纸淡入淡出；可取消导入，或恢复主题壁纸。
新图片保存在应用私有目录，重启、更新 APK 和推送主题后仍保留；不打包进 APK。

也支持从文件管理器将图片“分享”到本桌面，确认后才导入。

## 首页应用管理

应用库分为两区：上方“首页应用”按主页真实顺序排列并显示序号，下方“其他应用”用多行网格显示。
对首页应用长按确定，选择“调整首页顺序”：左右移动卡片，确定保存，返回取消。
移动时仅修改草稿，卡片序号即时更新，确认时才写入一次存储并同步主页。
所有应用短按均直接打开；长按其他应用可添加到首页或查看信息，长按首页应用可排序或移除。
添加或移除后重新读取首页应用，重置轮播动画、焦点索引并重建可见封面，避免旧画面与新列表混用。
刷新仅重建轮播卡片，不重启整个桌面或重新解码壁纸；普通返回首页仍复用缓存。
两个区域都用可回收列表，仅按需加载图标；80×80 图标缓存最多 16 张（像素数据约 400 KiB），
关闭应用库时释放列表和缓存，不改变原网格桌面的旧应用库。

进入“全部应用”后：

- 对不在首页的应用长按确定：从菜单选择“添加到首页”。
- 对已在首页的应用长按确定：选择“移出首页”或“调整首页顺序”。
- 对已在首页的应用短按确定：正常打开应用。

应用选择和顺序保存在应用私有目录，重启、更新 APK 或重新推送主题后仍保留。
排序文件 `cover_flow_order.txt` 与旧网格排序独立，不修改任何厂商配置。

## 性能约束

- 五张可见卡片共用应用封面，不因循环重复创建图片。
- 封面采用 200×300 ARGB 缓存，最多六张（包含切换过程），像素内存上限约 1.37 MiB。
- 仅生成可见及即将显示的封面；返回首页时应用未变就复用，应用库图标按需加载。
- 绘制时复用矩阵、路径、画笔、字体、渐变和矩形，不逐帧解码、创建封面或执行模糊。
- 不使用逐卡片离屏透明图层，降低 GPU 临时纹理需求；停留首页时不播放循环动画。
- 后台收到内存紧张通知时释放封面和解码后的壁纸，返回时按需恢复。

这些上限只指封面像素缓存，不是整个进程的内存；实际总占用还包括壁纸、系统渲染缓冲和运行时。

封面使用应用自身图标加原创竖版设计，不拉伸横版横幅。Android 11 上的毛玻璃
采用一次性低分辨率壁纸采样与透明叠层，不依赖 Android 12 的实时模糊接口。
将 `cover_flow` 改为 `false` 可回到原来的网格布局。
设备上的 BBLL 包名是 `com.V2.blb5`，APK 标签为 `BBLL5.2`。

壁纸复用项目自带的 `themes/scenes/wallpapers/03-moon-lake.jpg`，
复制为本目录的 `wallpaper.jpg`。可替换为自己的 1920×1080 JPEG。

主题不启用按键接管，不停用应用，也不改变默认桌面。
先单独安装并启动 CleanYourTV，再应用主题试用。

```powershell
tools\theme.ps1 -TvHost 192.168.100.169 themes\xgimi-personal
```

应用主题会重启 CleanYourTV，但不会设置默认 HOME。
